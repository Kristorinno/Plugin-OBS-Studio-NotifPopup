# Plugin-OBS-Studio-NotifPopup
Plugin para OBS, que permite presentar una notificación emergente "estilo Apple" sobre una fuente. Puede usarse para protecciones en vivo sobre una pantalla secundaria utilizando "abrir proyector de programa" y seleccionando su segunda pantalla o proyector de pantalla LED. Proyecto desarrollado con VibeCoding, para uso en iglesias o eventos.
